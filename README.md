# Showcase

What we build at Sparky Venture Labs, written up: Savant integrations for gear Savant doesn't cover, UniFi tied
into the control system, Mac tooling, and hardware.

Each write-up covers the problem, what we built, and how it turned out. The source, the profiles and the
step-by-step stay private. If you want one of these in your house or your project, get in touch.
